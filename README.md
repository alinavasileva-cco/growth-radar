# Growth Radar

Рабочая база поиска российских частных компаний для коммерческого и управленческого консалтинга Алины Васильевой.

## Критическое ограничение

Этот репозиторий используется только для discovery, квалификации, доказательств и хранения маршрутов связи. Он **не является источником текста или сценария рассылки**.

Автоматический outreach из репозитория запрещён. Нельзя использовать или подменять утверждённый персонализированный outreach универсальным шаблоном, исследованием, опросом, анкетой, приглашением в форму или позиционированием Growth Radar как B2B-платформы.

Обязательный guard: [`OUTREACH_GUARD.md`](OUTREACH_GUARD.md).
Главный источник правил discovery и квалификации: [`CURRENT_WORKING_CONFIG.md`](CURRENT_WORKING_CONFIG.md).

## Актуальные данные

Каноническая кампания: `data/campaigns/new_5000/`.

Основные сущности:
- `leads_master` / `contactable_master` — канонические квалифицированные компании;
- contacts/contact shards — подтверждённые маршруты связи;
- evidence — подтверждающие источники;
- run logs / reports — история запусков и проверки integrity;
- runtime — текущее состояние кампании.

Контакты могут использоваться для outreach только в отдельной явно заданной пользователем задаче и только после сверки с последним подтверждённым качественным outreach-baseline.
