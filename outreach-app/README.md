# Growth Radar Outreach

Отдельное PWA-приложение внутри `growth-radar` для подготовки и безопасной отправки индивидуальных писем.

## Состав MVP

- Google OAuth и Gmail API без пароля;
- синхронизация компаний из Growth Radar;
- ручное добавление и импорт XLSX/CSV;
- карточки компаний;
- персонализированные черновики без платного AI;
- редактор, одобрение и тест себе;
- PDF-презентация;
- отправка сейчас и очередь;
- лимиты и журнал;
- мобильный интерфейс.

## Для реального запуска нужны однократно

- PostgreSQL;
- HTTPS-домен приложения;
- Google OAuth Client для этого домена;
- переменные из `.env.example`.

Настоящие ключи и токены в репозиторий не добавляются.
