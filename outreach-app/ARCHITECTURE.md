# Growth Radar Outreach — архитектура MVP

## Где находится приложение

Приложение размещено отдельно в `outreach-app/` внутри единственного разрешённого репозитория `growth-radar`. Канонические CSV поиска компаний не изменяются приложением.

## Поток данных

1. Кнопка «Синхронизировать Growth Radar» читает опубликованный `contactable_master.csv`.
2. Компании обновляются по `Lead ID`; ручные статусы писем и отправок не перезаписываются.
3. Письмо создаётся только из полей карточки компании и профиля Алины.
4. Любое редактирование возвращает письмо в статус проверки.
5. Отправка разрешена только после отдельного одобрения.
6. Gmail создаёт Gmail Draft и только затем отправляет его.

## Безопасность

- вход ограничен значением `ALLOWED_EMAIL`;
- пароль Gmail не используется;
- OAuth-токены зашифрованы AES-256-GCM;
- cookie сессии HttpOnly, SameSite=Lax, Secure в production;
- Gmail scope MVP: `gmail.compose`, без чтения входящих;
- очередь выключена по умолчанию;
- дневной лимит, интервал, suppression list и блокировка повторного адреса;
- секреты находятся только в переменных окружения.

## Проверка

Первый реальный тест всегда выполняется на адрес самой Алины. Массовая отправка в MVP отсутствует: каждое письмо требует отдельного одобрения.
